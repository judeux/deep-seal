# Current project state scope

이 파일은 `docs/project/current-state.md`의 volatile implementation snapshot에 적용된다.

- Current state는 code, tests, Unity assets, Git와 verification evidence에서 확인한 사실만
  기록한다. 새로운 design이나 architecture를 결정하지 않는다.
- Active work unit, owner, branch/worktree, main baseline, Unity version, implemented scope,
  verification baseline, known issue와 next gate를 짧게 유지한다.
- 완료 history는 roadmap archive 또는 historical implementation 문서에 link하고
  반복하지 않는다.
- `Implemented`, `Verified`, `Deferred`를 구분하고 미확인 정보는 `Needs verification`으로
  표시한다.
- Work unit 시작, verification, integration 또는 roadmap 변경 뒤 owner agent가 갱신한다.
- Code와 문서가 충돌하면 현재 state를 임의로 고치지 말고 conflict와 필요한 결정을
  보고한다.
